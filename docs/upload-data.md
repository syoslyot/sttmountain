# Uploading Expedition Data

這份文件給負責整理出隊資料的幹部使用。資料放進 Google Drive 後，CI 或手動同步流程會把資料整理進 Supabase。

## Solo Expedition

```text
所有出隊資料夾/
  [{天數}{級數}{類別}]{隊伍名稱}_{日期}/
    {隊伍名稱}_直企.xlsx
    上繳航跡與紀錄/
    地圖/
```

要求：

- 隊伍資料夾必須符合 `[{天數}{級數}{類別}]{隊伍名稱}_{日期}`，例如 `[2D活]舊古樓嘍嘍_20260418`。
- 左右中括號可使用半形 `[]` 或全形 `［］`。
- 同步程式只強制檢查左括號、天數、級數、右括號與後方隊伍名稱；日期與隊伍名稱之間可以沒有 `_`。
- 直企檔名只要包含 `直企` 或隊伍名稱其中之一即可。
- 隊伍資料夾沒有直企檔案時，不會建立隊伍資料。
- `上繳航跡與紀錄` 可放 gpx、kml、txt、md、docx、pdf、Google 文件，也可以再分子資料夾。
- `地圖` 可放 pdf、docx、jpg、png、jpeg。

## Group Activity

```text
所有出隊資料夾/
  {活動名稱}/
    [{天數}{級數}{類別}]{隊伍名稱A}_{日期}/
      {隊伍名稱A}_直企.xlsx
      上繳航跡與紀錄/
      地圖/
    [{天數}{級數}{類別}]{隊伍名稱B}_{日期}/
      {隊伍名稱B}_直企.xlsx
      上繳航跡與紀錄/
      地圖/
```

每個隊伍資料夾各自需要一份直企。

## Folder Names

子資料夾名稱需精確符合：

```text
上繳航跡與紀錄
地圖
```

名稱不同會導致同步腳本無法分類。

這兩個資料夾底下可以再建立子資料夾，同步程式會遞迴往下找檔案。其他檔案或資料夾會被略過。

分類規則：

- `上繳航跡與紀錄` 底下的 `.gpx` / `.kml` 會歸類為航跡。
- `上繳航跡與紀錄` 底下其他支援格式會歸類為紀錄。
- `地圖` 底下只處理地圖支援格式。

## Sync Window

目前同步只處理 `2026-05-15` 以後建立的資料夾。舊資料若要補入，請先和維護者確認同步策略。

## Common Upload Mistakes

- 隊伍資料夾沒有符合 `[天數級數]隊伍名稱` 的基本格式。
- 隊伍資料夾沒有直企檔案。
- 把 GPX 放進 `地圖`。
- 把上繳紀錄放在隊伍資料夾根目錄。
- 大眾化活動少一層隊伍資料夾。
- Google 文件權限或檔案狀態導致 Service Account 無法讀取。
